# Security Policy

## Reporting a Vulnerability

SnapSafe AI takes security and user privacy with extreme seriousness.

If you believe you have discovered a vulnerability, data leakage vector, or unexpected egress behavior, please report it confidentially to:
**security@snapsafe-ai.internal**

Please include:
- Description of the threat vector
- Steps to reproduce
- Sample test image (synthetic only, never real PII)

## Zero Cloud Egress Guarantee
SnapSafe AI guarantees 0 bytes of external network transmission during screen capture, OCR, detection, and redaction operations.
All processing executes locally in memory.
